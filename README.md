# Pure Diamond ECD School — High-Fidelity Frontend

This project recreates the supplied Pure Diamond ECD School website visual as a responsive React + Vite frontend.

## Included
- Desktop and mobile responsive layout
- Supplied Pure Diamond logo
- Supplied school flyer artwork
- Classroom imagery cropped from the supplied UI reference for the Nursery cards
- Smooth anchor navigation
- Sticky navigation bar
- Scroll reveal animations
- Floating logo / orbit animation
- Hover lift and image zoom effects
- Animated scroll-down indicator
- Back-to-top button
- Responsive mobile menu
- Functional enrollment modal with form state
- Click-to-call and WhatsApp links
- Gallery section
- Footer and all major sections visible in the reference

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

The content is intentionally editable in `src/main.jsx`, especially the school contact details and admission form handling.
